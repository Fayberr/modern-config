# Modern Config - Modrinth page copy

## description

Clear settings menus for Minecraft mods, with live previews and easy reset controls.

## body

Modern Config gives supported mods a clear, consistent settings screen.

Options are arranged in scrolling panels with toggles, sliders, dropdowns and text fields. Changes preview while you edit, **Save** keeps them, and **Cancel** or Escape restores the previous settings. Options with a default value can be reset individually.

### Installation

Requires Modern GUI and Fabric API. Install it when a mod asks for it, or to use a supported mod's Modern Config settings screen.

When Cloth Config is installed, the optional bridge can give compatible Cloth Config screens the same appearance.

Use **/modernconfig demo** to try the available controls.
